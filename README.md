# 小红书账号创建日期

一个用于小红书网页版的 Tampermonkey 用户脚本。

脚本会在用户主页中读取 URL 里的用户 ID，根据用户 ID 前 8 位所包含的时间戳信息推算账号创建日期，并显示在“小红书号”和“IP属地”附近。

## 效果

页面原本显示：

```text
小红书号：27765779615 | IP属地：安徽
```

安装脚本后显示：

```text
小红书号：27765779615  创建于 2022-08-24 | IP属地：安徽
```

鼠标悬停在创建日期上时，会显示对应的用户 ID 以及“根据用户 ID 推算”的提示。

## 功能

- 自动识别小红书用户主页
- 从 `/user/profile/<userId>` 中提取用户 ID
- 根据用户 ID 前 8 位解析时间戳
- 仅显示年月日
- 使用中国标准时间 `Asia/Shanghai`
- 支持小红书网页版 SPA 页面切换
- 切换不同博主主页时自动刷新日期
- 过滤明显异常的日期
- 不请求额外接口，不采集用户数据

## 安装

### 1. 安装 Tampermonkey

先在浏览器中安装 Tampermonkey 扩展。

### 2. 导入脚本

打开 Tampermonkey 管理面板，新建脚本，然后将：

```text
xiaohongshu-account-date.user.js
```

中的代码复制进去并保存。

### 3. 打开小红书网页版

访问任意用户主页，例如：

```text
https://www.xiaohongshu.com/user/profile/xxxxxxxxxxxxxxxxxxxxxxxx
```

如果该用户 ID 可以正常解析，脚本会自动显示推算的创建日期。

## 原理

小红书部分用户 ID 为 24 位十六进制字符串，例如：

```text
6a8aaa97000000000301d1a3
```

脚本读取前 8 位：

```text
6a8aaa97
```

并将其作为 Unix 时间戳解析，然后转换为日期。

核心逻辑类似：

```javascript
const timestamp = parseInt(userId.slice(0, 8), 16);
const date = new Date(timestamp * 1000);
```

## 说明

本脚本显示的日期是根据用户 ID 中的时间戳信息推算得到的。

它不代表小红书官方提供的“注册时间”字段，也不能保证所有账号都完全符合这一规则。因此，更准确的理解是：

> 根据用户 ID 推算的账号创建时间。

如果用户 ID 格式不符合预期，或者解析出的时间明显异常，脚本会跳过显示。

## 兼容性

目前主要针对：

- 小红书网页版
- Tampermonkey
- Chromium 系浏览器

由于小红书可能随时调整网页 DOM 结构，未来如果页面结构发生变化，脚本中的元素定位逻辑可能需要更新。

## 隐私

脚本仅在本地浏览器中运行。

它不会：

- 上传浏览记录
- 收集小红书账号信息
- 向第三方服务器发送数据
- 调用额外的小红书接口
